# renterd Smart Autopilot

Experimental Smart Autopilot build for Sia renterd.

This project is an unofficial modified build of Sia Foundation renterd and is not an official Sia Foundation release.

## Status

Development version.

Binary releases for Windows amd64 will be published in the GitHub Releases section.

## Base project

Based on Sia Foundation renterd v2.9.4.

Upstream project:
https://github.com/SiaFoundation/renterd
